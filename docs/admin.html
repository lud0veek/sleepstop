🌐 Relier ton domaine OVH sleepstop.eu à Firebase

Avec Firebase Hosting, tu profites du CDN mondial Google + HTTPS gratuit sans utiliser l'hébergement OVH :

  1. Ouvre la Console Firebase Hosting (sleepstop-eu).
  2. Clique sur Ajouter un domaine personnalisé et tape sleepstop.eu.
  3. Copie les 2 enregistrements A (IP) fournis par Firebase dans ta Zone DNS OVH.
  4. URL de Politique de Confidentialité à coller dans Google Play Console :
    https://sleepstop-eu.web.app/privacy (ou https://sleepstop.eu/privacy)
